# vault-mirror

Keeps one Obsidian vault and one local ruvector index in step, so your AI searches the index first.
It only reads your notes. Your notes are never changed.

Status: version 0.1.0, built to `docs/SPEC.md`. Verified on Apple Silicon Macs. Windows, Intel Macs and Linux are not yet verified.
